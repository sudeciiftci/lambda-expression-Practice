# Java Lambda Expression Practice

This project demonstrates **lambda expressions** in Java using functional interfaces.

## Concepts
- Functional interfaces
- Lambda expressions
- Passing parameters
- Returning values with lambdas

## Examples

### Sum
- Adds two numbers using a lambda expression.

### GradeChecker
- Checks a student's grade and returns:
  - Excellent
  - Good
  - Pass
  - Fail

### Discount
- Calculates shopping discounts based on:
  - Student status
  - Purchase amount

### Login
- Simulates a simple login system.
- Checks username and password using a lambda expression.

## Purpose
- Understand lambda syntax
- Practice functional programming in Java
- Replace anonymous classes with cleaner code

## Run
Run each main class (`LambdaExpression`, `StudentGradeChecker`, `ShoppingDiscount`, `LoginSystem`) separately.
